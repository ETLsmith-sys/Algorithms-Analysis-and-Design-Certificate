# Algorithms Analysis and Design from scratch

**Certificate of Completion** — Cloud Native Base Camp (~2024)

This repository documents my completion of *Algorithms Analysis and Design
from scratch*, a course covering algorithmic complexity analysis and core
algorithm design paradigms. Completed during my backend development
foundation, prior to transitioning into Data Engineering.

## 📜 Certificate
See [`certificate.pdf`](./certificate.pdf) for the official certificate.

## 📚 Topics Covered

- **Mathematical Foundations** — circle area, sigma notation, standard
  deviation (algorithm, model, and code)
- **Algorithm Analysis**
  - Introduction to algorithmic analysis
  - Calculus-based function analysis
  - Big O Notation
  - Drawing complexity classes on a graph
- **Sorting Algorithms**
  - Insertion Sort — algorithm, code, and analysis
- **Divide & Conquer**
  - Merge Sort — algorithm, code, and analysis
  - Binary Search — algorithm and code
  - Segregating positive and negative numbers
- **Optimization** — calculus-based max-profit optimization problems
- **Greedy Algorithms**
  - Activity Selection Problem
  - Huffman Coding
  - Fractional Knapsack Problem
  - Sorted character frequency problems
- **Dynamic Programming**
  - Stagecoach Problem
  - Longest Common Subsequence
  - 0/1 Knapsack Problem
- **Graph Algorithms**
  - Prim's Minimum Spanning Tree
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
  - Dijkstra's Shortest Path
